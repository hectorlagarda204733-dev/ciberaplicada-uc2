# Referencias oficiales

Se emplea **OWASP Top 10:2021**, una de las versiones aceptadas por la consigna. No se mezclan posiciones de distintas ediciones.

1. **A01:2021 — Broken Access Control.** Autorización en backend, mínimo privilegio y propiedad de registros.
   https://owasp.org/Top10/2021/A01_2021-Broken_Access_Control/
2. **A03:2021 — Injection.** Incluye CWE-79, Cross-site Scripting.
   https://owasp.org/Top10/2021/A03_2021-Injection/
3. **A10:2021 — Server-Side Request Forgery.** Allowlist, redirecciones, DNS y segmentación de red.
   https://owasp.org/Top10/2021/A10_2021-Server-Side_Request_Forgery_%28SSRF%29/
4. **OWASP Authorization Cheat Sheet.**
   https://cheatsheetseries.owasp.org/cheatsheets/Authorization_Cheat_Sheet.html
5. **OWASP Cross Site Scripting Prevention Cheat Sheet.**
   https://cheatsheetseries.owasp.org/cheatsheets/Cross_Site_Scripting_Prevention_Cheat_Sheet.html
6. **OWASP Content Security Policy Cheat Sheet.**
   https://cheatsheetseries.owasp.org/cheatsheets/Content_Security_Policy_Cheat_Sheet.html
7. **OWASP Server Side Request Forgery Prevention Cheat Sheet.**
   https://cheatsheetseries.owasp.org/cheatsheets/Server_Side_Request_Forgery_Prevention_Cheat_Sheet.html
8. **MDN — Content-Security-Policy.** Sintaxis y comportamiento del encabezado.
   https://developer.mozilla.org/en-US/docs/Web/HTTP/Reference/Headers/Content-Security-Policy
