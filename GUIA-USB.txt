EXPOSICION UC2 - VERSION PORTABLE PARA USB
=======================================

REQUISITOS
Windows 10/11 de 64 bits y un navegador, por ejemplo Microsoft Edge.
Node.js y las herramientas del proyecto vienen incluidos.
No necesitas instalar programas, usar Internet ni ser administrador para exponer.

PARA EMPEZAR
1. Abre INICIAR.cmd con doble clic.
2. Deja abierta la ventana negra. Se abriran las dos versiones en tu navegador:
   Vulnerable: http://127.0.0.1:3000
   Mitigado:   http://127.0.0.1:3001
3. En ambas inicia sesion con ana y contrasena demo123.
4. Abre presentacion\Exposicion-UC2.pdf en tu navegador.
   Alternativa sin PowerPoint: presentacion\Exposicion-UC2.html.
5. Abre lectura\GUION.txt en el Bloc de notas: dice que hacer y que explicar.

QUE DEMOSTRAR
ACCESO ROTO: con Ana cambia /notas/1 por /notas/2. En 3000 ves la nota de Bruno;
en 3001 recibes 403. Explica la comprobacion del propietario en el servidor.

XSS: en /xss envia el comentario precargado. En 3000 aparece una alerta;
en 3001 se muestra como texto. Compara tambien /csp-prueba para explicar CSP.

SSRF: en /ssrf consulta http://127.0.0.1:9101/secreto. En 3000 se muestra el
secreto ficticio; en 3001 se bloquea. El catalogo permitido sigue funcionando.
Explica la lista exacta de destinos permitidos y el bloqueo de redirecciones.

MATERIAL
presentacion\Exposicion-UC2.pptx = editable, con notas del presentador.
presentacion\Exposicion-UC2.pdf  = listo para presentar en el navegador.
lectura\GUION.txt               = guion de 15 minutos.
lectura\CORREO.txt              = plantilla del correo de entrega.
lectura\USO-IA.txt              = declaracion de IA y revisiones por completar.
vulnerable y mitigado           = codigo que debes mostrar y explicar.
compartido                      = utilidades necesarias para ambas versiones.

Los archivos de lectura son copias de los .md originales para abrirlos facilmente.
Si personalizas los documentos, mantén actualizadas ambas copias.
Completa los nombres y matriculas en la presentacion antes de entregar.
Si editas el PPTX, exporta un PDF actualizado desde tu editor de presentaciones.

PARA TERMINAR
En la ventana negra presiona Ctrl+C y cierra la consola.
Cierra los documentos abiertos y expulsa el USB desde Windows.

SI ALGO FALLA
- Puerto ocupado: cierra la otra ejecucion del laboratorio y vuelve a iniciar.
- Pagina sin sesion: inicia sesion en cada version por separado.
- No se abren las pestanas: escribe las dos direcciones manualmente.
- No tienes PowerPoint: usa el PDF o HTML; el laboratorio no necesita Office.

HERRAMIENTAS OPCIONALES
Abre CONSOLA-PORTABLE.cmd para una terminal con Node y npm del USB.
npm test comprueba el laboratorio; npm run test:browser comprueba Edge.
npm run slides regenera PPTX/PDF/HTML y reemplaza los archivos generados.
Las dos ultimas tareas necesitan Microsoft Edge instalado; exponer no requiere
regenerar nada. Las dependencias ya vienen incluidas, sin descargas adicionales.

PORTABILIDAD
Puedes cambiar la letra del USB o copiar TODA esta carpeta a otra PC Windows x64.
Conserva runtime y node_modules para mantener disponibles todas las herramientas.
El lanzador no depende de la ruta C:\Users\Hector ni de la letra E:.
